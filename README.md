# ربات IRAN NARRATIVE برای روبیکا

ربات دو بخش دارد: **مخاطبین** (مشاهده‌ی پست‌ها، ارسال نظر، درباره ما) و **ادمین‌ها** (پنل مدیریت با ورود نام + رمز).

## ساختار پروژه

| فایل | وظیفه |
|---|---|
| `config.py` | تنظیمات و مقادیر پیش‌فرض (نام ادمین، رمز، متن خوش‌آمدگویی) |
| `database.py` | ذخیره‌سازی در SQLite، هش رمزها، یکسان‌سازی متن فارسی |
| `logic.py` | منطق کامل ربات (ماشین حالت)، **مستقل از پلتفرم** |
| `rubika_api.py` | کلاینت Bot API رسمی روبیکا |
| `main.py` | حلقه‌ی دریافت آپدیت و ارسال پاسخ |

## راه‌اندازی

1. در روبیکا با ربات `@botfather` یک ربات بسازید و **توکن** را بگیرید.
2. نصب وابستگی‌ها (پایتون 3.9 یا بالاتر):
   ```bash
   pip install -r requirements.txt
   ```
3. تنظیم توکن و اجرا:
   ```bash
   # لینوکس / مک
   export RUBIKA_BOT_TOKEN="توکن-شما"
   # ویندوز (PowerShell)
   $env:RUBIKA_BOT_TOKEN="توکن-شما"

   python main.py
   ```
4. در روبیکا ربات را باز کنید و `/start` بزنید.

## ورود ادمین (پیش‌فرض)

- نام: `محمد امین روحانی`
- رمز: `@IRAN NARRATIVE`

**بلافاصله بعد از اولین ورود، از «تغییر رمز ورود» رمز را عوض کنید.**
این مقادیر فقط در اولین اجرا در دیتابیس ساخته می‌شوند (رمزها به‌صورت PBKDF2 هش‌شده ذخیره می‌شوند، نه متن ساده).

## امکانات پنل ادمین

- **افزودن پست:** فایل/ویدیو را بفرستید؛ کپشن را همراه فایل یا در پیام بعدی بنویسید (`-` یعنی بدون کپشن).
- **مدیریت پست‌ها:** حذف پست با شماره.
- **مشاهده نظرات:** ۲۰ نظر اخیر؛ نظرات جدید با 🆕 مشخص می‌شوند.
- **ویرایش درباره ما** و **تغییر نام ربات** (نام در پیام منوی اصلی نمایش داده می‌شود).
- **تغییر رمز ورود** (برای ادمینِ واردشده) و **افزودن ادمین** (نام + رمز مخصوص خودش).
- **غیرفعال/فعال کردن ربات:** در حالت غیرفعال، مخاطبین پیام تعمیر می‌بینند ولی ادمین‌ها همچنان وارد می‌شوند.

## ساختار دیتابیس (`bot.db`)

| جدول | ستون‌های مهم |
|---|---|
| `settings` | `key`, `value` (نام ربات، متن خوش‌آمد، درباره ما، `bot_enabled`، `offset_id`) |
| `admins` | `name`, `name_norm`, `password_hash` |
| `posts` | `file_id`, `file_name`, `caption`, `created_by`, `created_at` |
| `feedbacks` | `chat_id`, `text`, `is_read`, `created_at` |
| `sessions` | `chat_id`, `state`, `data` (JSON), `admin_name`, `fail_count`, `locked_until` |

## نکات امنیتی

- پس از ۵ رمز اشتباه، ورود آن چت به مدت ۵ دقیقه قفل می‌شود (قابل تنظیم در `config.py`).
- ربات نمی‌تواند پیام رمز شما را از چت پاک کند؛ بعد از وارد کردن یا تغییر رمز، پیام را خودتان حذف کنید.
- فایل `bot.db` و توکن را در گیت یا جای عمومی قرار ندهید.
- نام ادمین‌ها حساس به فاصله‌ی اضافه، «ی/ي»، «ک/ك» و نیم‌فاصله نیست.

## انتقال به پلتفرم دیگر

کل منطق در `logic.py` است و فقط یک تابع دارد: `handle(chat_id, text, file) -> list[Reply]`.
برای پلتفرم دیگر (بله، تلگرام، rubpy و...) فقط `rubika_api.py` و `main.py` را بازنویسی کنید.

## نکات مهم

- ربات با **Polling** (`getUpdates`) کار می‌کند؛ برای سرور دائمی می‌توانید با `systemd` یا `supervisor` آن را اجرا کنید.
- ارسال مجدد فایل‌ها با `file_id` ذخیره‌شده انجام می‌شود (بدون آپلود دوباره).
- کدِ ارتباط با روبیکا بر اساس مستندات Bot API نسخه‌ی v3 نوشته شده و روی سرور واقعی با توکن شما تست نشده است. اگر روبیکا ساختار پاسخ‌ها را تغییر داد، فقط `rubika_api.py` و تابع `extract` در `main.py` نیاز به اصلاح دارند. مستندات: https://botapi.rubika.ir
- تاریخ نظرات میلادی نمایش داده می‌شود؛ برای شمسی می‌توانید `jdatetime` را اضافه کنید.
